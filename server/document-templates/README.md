# Робочі шаблони документів

Ця директорія використовується сервером для шаблонної генерації docx-документів.

## Файли

- `appendix3.template.docx` — робоча копія Додатку 3, заяви на приєднання.
- `appendix4.template.docx` — робоча копія Додатку 4, опитувального листа для тепловикористальних установок.
- `appendix5.template.docx` — робоча копія Додатку 5, опитувального листа для теплогенеруючих/когенераційних установок.

Оригінальні офіційні зразки лежать у `client/public/documents` і не редагуються.

## Як додати плейсхолдери

1. Відкрийте потрібний `.template.docx` у Word або LibreOffice.
2. Вставте плейсхолдери з `TEMPLATE_FIELDS.md` у потрібні місця документа.
3. Зберігайте плейсхолдер як цілісний текст, наприклад `{customerName}`.
4. Не розбивайте плейсхолдер переносами, стилями або пробілами.
5. Не змінюйте юридичний текст документа без окремого погодження.

## Перевірка після редагування

Після збереження шаблонів запустіть:

```bash
npm run check:template-placeholders -w server
npm run check:template-generation -w server
```

Для повної перевірки мапінгу документів:

```bash
npm run check:document-mapping -w server
```

## Fallback

Якщо шаблон відсутній, не містить плейсхолдерів або не проходить шаблонізацію, сервер автоматично використовує стару програмну генерацію документа. Користувач не бачить технічну помилку, якщо fallback успішний.

## Додатки 1/2

Додаток 1 і Додаток 2 на цьому етапі не шаблонізуються. Вони залишаються на програмній генерації до окремого етапу.
