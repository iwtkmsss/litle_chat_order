# Little Chat Order

Базовая рабочая область для маленького проекта с:

- фронтендом на `Vite + React`
- бекендом на `Express`
- готовой связкой между клиентом и API

## Быстрый старт

```bash
npm install
npm run dev
```

После запуска:

- клиент: `http://localhost:5173`
- сервер: `http://localhost:3001`

## Структура

```text
client/  # интерфейс на Vite
server/  # API на Express
```

## Что уже подготовлено

- `npm workspaces` в корне
- dev-запуск клиента и сервера одной командой
- Vite proxy на `/api`
- базовый endpoint `GET /api/health`
- стартовая UI-страница под будущий чат
